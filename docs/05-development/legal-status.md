# Estado legal y distribución de HiQNet POS

**Decisión aprobada por HiQNet.** Este documento formaliza el modelo de
distribución del repositorio y del producto. No constituye una EULA, contrato
de suscripción, SLA ni contrato de soporte: esos términos comerciales se
establecerán por separado donde corresponda.

## Modelo de distribución

```text
Distribution model:
Proprietary commercial software

Repository:
Private

Open-source license:
None

Copyright:
All Rights Reserved

Source-code reuse:
Not granted by default

Customer rights:
Separate written commercial agreement

v0.1.0:
Private technical Foundation release

Commercial/customer launch:
Still requires customer-facing contractual terms before the first external paid deployment
```

## Puntos normativos

- **HiQNet POS es software propietario de HiQNet.** Todo el contenido del
  repositorio (código fuente, documentación, esquemas de base de datos, diseño,
  configuración y materiales relacionados) es propietario.
- **NO es open source** y **no se concede licencia general de reutilización**:
  usar, copiar, modificar, redistribuir, sublicenciar, vender, publicar o crear
  trabajos derivados requiere autorización expresa en un **acuerdo escrito
  separado** con HiQNet.
- El acceso al repositorio, la posesión de una copia o el acceso al código
  fuente **no transfieren propiedad ni otorgan licencia** sobre derechos de
  propiedad intelectual.
- Los clientes obtendrán derechos de uso únicamente mediante **contractos /
  acuerdos comerciales separados** con HiQNet.
- Las librerías, dependencias, frameworks y componentes de terceros siguen
  sujetos a sus respectivas licencias y avisos.

## Relación con v0.1.0

```text
GitHub private release/tag
!=
commercial customer license
```

La release técnica privada `v0.1.0` documenta un hito técnico de la Foundation;
no otorga por sí misma derechos comerciales a ningún cliente ni tercero. La
primera **release comercial estable** sigue siendo `v1.0.0` (ver
`docs/05-development/release-process.md`).

## Trabajo precomercial pendiente

La **EULA / contratos de servicio / suscripción / SLA** pueden definirse antes
del primer piloto o despliegue con cliente externo. No se inventan aquí
cláusulas fiscales, SLA, jurisdicción ni responsabilidades comerciales: esos
términos los debe definir HiQNet comercialmente.

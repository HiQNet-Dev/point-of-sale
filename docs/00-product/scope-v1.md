# Alcance v1 — visión comercial tentativa

**Importante:** este documento describe alcance **futuro** para una hipotética
**v1.0.0 comercial**. **Nada de lo listado existe hoy.** El repositorio contiene
solo la fundación técnica (estructura compilable, ejecutable y documentada).
Todo lo descrito aquí está **no implementado / futuro**.

Versión actual: `0.1.0` (Foundation). La v1.0.0 **no está alcanzada**.

## Must-have (futuro, no implementado)

| Área | Funcionalidades futuras |
| --- | --- |
| Empresa | Organizaciones (enterprise), sucursales (branches) |
| Acceso | Usuarios, roles y permisos |
| Catálogo | Productos, variantes (tamaños, sabores), precios |
| Caja | Cajas (cash registers), arqueos/turnos (shifts) |
| Venta | Ventas, pagos, tickets |
| Inventario | Existencias, ingredientes, recetas |
| Compras | Órdenes de compra, proveedores |
| Gastos | Gastos del negocio, mermas/shrinkage y pérdidas |
| Gestión | Reportes, auditoría (audit) |

## Posterior (futuro, fuera del alcance inmediato)

- CFDI / facturación electrónica
- Fidelización (loyalty)
- Ecommerce
- KDS (kitchen display)
- Terminal bancaria (TPV/lectores)
- Modo offline
- Hardware POS (impresora térmica, cajón, lectores) vía shell Electron futura

## Fuera de alcance para v1

- Multi-tenant SaaS (el modelo previsto son instalaciones aisladas por cliente)
- Suscripciones y cobros dentro del producto (licenciamiento: futuro aparte)
- Marketplace

## Declaración explícita

**Ninguna de las funcionalidades de este documento existe hoy.** Ninguna debe
darse por entendida en una demo, contrato o promesa comercial sin confirmar que
su milestone correspondiente (ver `docs/00-product/roadmap.md`) esté completada.
